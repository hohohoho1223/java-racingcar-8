# java-racingcar-precourse

## 기능 요구 사항

초간단 자동차 경주 게임을 구현한다.

- 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- 각 자동차에 이름을 부여할 수 있다. 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
- 자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.
- 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다. 
- 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다. 
- 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다. 
- 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다. 
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.

## 구현할 기능 목록

- [x] 애플리케이션 실행 기능
- [x] 사용자에게 자동차 이름 입력을 요청하는 기능
  - 경주할 자동차 이름(이름은 쉼표(,) 기준으로 구분)
- [x] 시도할 횟수 입력 기능
- [x] 도메인 기능
    - [x] Car
        - [x] 자동차 이름과 이동 거리(위치)를 관리한다.
        - [x] 자동차 이름은 1자 이상, 5자 이하로 제한한다.
        - [x] 무작위 값이 4 이상일 경우 자동차를 전진시킨다.
    - [x] Cars
        - [x] 여러 대의 자동차를 관리하는 일급 컬렉션으로 구현한다.
        - [x] 모든 자동차를 한 번씩 이동시킨다.
        - [x] 가장 멀리 이동한 자동차(들)를 계산한다.
    - [x] RacingGame
        - [x] 시도 횟수만큼 라운드를 반복한다.
        - [x] 각 라운드별 이동 결과를 관리한다.
        - [x] 최종 우승자 목록을 계산하여 반환한다.
- [x] 차수별 실행 결과를 콘솔에 출력하는 기능
  - [x] 단독 혹은 공동 우승자 안내 문구 출력 기능

## 발생할 수 있는 예외들

- 자동차 이름 입력 예외
    - 입력 값이 존재하지 않거나 공백만 입력된 경우
- 시도 횟수 입력 예외
    - 숫자가 아닌 값이 입력된 경우
- 도메인 계층 예외(자동차 이름 검증 예외)
    - `null` 값이 전달된 경우 (시스템 결함 가능)
    - 공백 문자열(`" "`) 또는 빈 문자열인 경우
    - 자동차 이름이 5자를 초과한 경우
